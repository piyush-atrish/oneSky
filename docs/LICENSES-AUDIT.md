## Recorded licence evidence

### Stellarium "modern" sky culture (checked 2026-10-24)
File: `skycultures/modern/description.md` in github.com/Stellarium/stellarium
- Authors: "Stellarium's team"
- Licence statement, verbatim: "Text and data: CC BY-SA 4.0. Illustrations: Free Art License"
- oneSky uses only data (constellation names and lines). No illustrations are bundled in `assets/`.
- Pinned commit used by the generators: daace2add6a1bf886e8ee1934f51e9c69f818d18

### HYG database v4.1 (checked 2026-10-24)
Page: astronexus.com/hyg - "The HYG database is licensed with the Creative Commons Attribution-ShareAlike 4.0 license." (v4.x). Older v3.x line listed as CC BY-SA 2.5, which is why the codebox v3 mirror was replaced.
- Compiled from the Hipparcos, Yale Bright Star and Gliese catalogs.
- Pinned commit used by the generator: e4fd9c95381c6b5f34e465259cb4d2e1a7ff2e09

### Changes made to the data (required by CC BY-SA)
- Stars: filtered to magnitude <= 6.5, duplicate entries merged, columns reduced to [hip, RA hours, Dec degrees, magnitude, B-V], values rounded.
- Lines: polylines of Hipparcos numbers converted to pairs.
- Entity text: original descriptions and subtitles written for oneSky; facts from HYG and NASA NSSDCA.

## Phase 3 record (2026-10-24)

How the list of shipped packages was made: `npx expo export --platform android --dump-sourcemap --no-minify`, then every `node_modules/<package>` path in the resulting source map (1,309 source files, 53 distinct packages). Only these packages are in the app; the other ~550 packages in `node_modules` are build tools and are not shipped.

Licence mix of the 53: MIT 47, ISC 2 (`@ungap/structured-clone`, `semver`), BSD-3-Clause 2 (`hoist-non-react-statics`, `ieee754`), MIT + OFL-1.1 2 (`@expo-google-fonts/righteous`, `@expo-google-fonts/roboto`). Build-tool packages with other licences (MPL-2.0 `lightningcss`, CC-BY-4.0 `caniuse-lite`, Python-2.0 `argparse`, `node-forge` BSD-3-Clause OR GPL-2.0) are not in the bundle.

Seven packages are published to npm without a licence file; their copyright lines were read from the upstream repositories' LICENSE files on 2026-10-24: `@react-native/*` and `metro-runtime` (Meta Platforms, Inc. and affiliates), `@react-three/fiber` (Poimandres), `astronomy-engine` (Don Cross).

Open item: native Android libraries bundled by React Native/Expo (not visible in the JS bundle). The About screen says they are used under their own licences. Verify the list against the release build in Phase 8.

Re-run `node scripts/generate-notices.mjs` whenever dependencies change (and refresh `scripts/bundled-packages.json` first).
